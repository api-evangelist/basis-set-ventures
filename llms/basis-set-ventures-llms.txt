# Basis Set Ventures

> Basis Set Ventures is an AI-native, early-stage venture capital firm founded in 2017 by Dr. Lan Xuezhao. The firm backs seed and early-stage founders building artificial intelligence: AI infrastructure, autonomous systems, molecular and materials discovery, agentic development tooling, and automated workflows. Basis Set announced a $250M Fund IV and positions itself as "the first capital when it's just you and your vision."

This is an API Evangelist network profile of Basis Set Ventures as a venture-capital firm.
